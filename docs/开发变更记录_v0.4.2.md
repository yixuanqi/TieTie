# v0.4.2 修复记录（2026-10-28）

## 真实反馈
- 飞书 `Ctrl+Shift+A` 截图可粘贴；PixPin 截图不可粘贴。
- 在 Todo Checklist 模式中，点击第三个「图片」样式按钮无法切换。

## 问题与处理
1. 第三个按钮在 0.4.1 实际是 `pasteBtn`，并且 Todo 模式被禁用；改为 `modeImage` 模式按钮，提供单独图片导入 UI。
2. PixPin 可以用普通位图或「复制图像为文件」方式写剪贴板，文件型图片可能是 PNG/WebP/AVIF；原 PowerShell 回退只处理几种图片扩展名。现在支持 CF_HDROP 文件型图片、注册的 PNG/JFIF/WebP 流和 GDI+ 位图。
3. 图片模式 `Ctrl+V` 直接请求 Rust，不依赖 WebView2 的 ClipboardEvent 图像格式；其他模式继续支持 WebView2 Blob 粘贴。
4. 修复保存队列中的当前卡片 ID 竞态。
5. 保留原数据目录和格式，未进行数据迁移。

## 已验证
- `node --check web/app.js`：通过。
- `node --check web/float.js`：通过。
- `python tests/ui_smoke.py`：通过（含 Todo→图片→文字→Todo，以及图片保存、预览、历史等模拟操作）。

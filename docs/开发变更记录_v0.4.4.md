# v0.4.4 · 面板尺寸与偏好设置

- 修复主面板不能用鼠标调整大小：自绘右下角 handle → `window.startResizeDragging('SouthEast')`，开启 `core:window:allow-start-resize-dragging`。
- 通过 `onResized()` 和 `innerSize()/scaleFactor()` 得到逻辑尺寸，650 ms 防抖后写入 `preferences.json`，启动恢复。
- 系统托盘添加「设置」菜单项，创建独立设置窗口；主面板新增设置图标。
- 亮色与暗色保留手绘排版、避免高强度玻璃模糊。设置保存后事件 `preferences-changed` 广播到主面板和浮贴。
- 快捷键采用 Windows 原生全局注册：先注册新组合，成功再注销旧组合，失败时保留旧设置；输入支持 Ctrl/Alt/Shift + A-Z、0-9、F1-F12。
- 旧版 `notes.json`、PNG 和缩略图的格式、路径及应用 identifier 不变。
- 主窗口取消 Tauri transparent 属性，降低 Windows 透明 WebView2 造成的背后桌面文字透显示风险；浮贴保持透明。
- Chromium 模拟验证：热键录入、设置保存、取消、暗色预览、主面板缩放路径、尺寸保存、原功能回归。原生 Windows 验收尚待执行。

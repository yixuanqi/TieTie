# 贴贴 · 产品设计说明（v0.3）

> **一句话定位**：随手存下，随时找回，想贴就贴。
>
> **产品形态**：Windows 常驻托盘的轻量桌面工具；快捷收集箱 + 可独立悬浮的桌面浮贴。
>
> **文档状态**：交互/视觉设计讨论稿。**用户数据如何存放、备份及迁移，留待下一轮专项讨论；本版不决定数据库、文件格式或云同步方案。**

**更新摘要（2026-10-28）**：统一支持 Windows 剪贴板中的文字与图片（不限 PixPin 来源）；明确关键字与按时间搜索；加入更夸张幽默、可控频率的 Todo 庆祝反馈；主面板/浮贴支持鼠标左键双击快速隐藏；保留极简、半透明、轻微手绘的视觉方向。

---

## 01 · 为什么做

用户经常复制图片、截图、技术资料、命令或零散文字，不想逐一命名保存文件，更不想持续打开庞大的笔记应用。需要时，希望像 PixPin 一样把一条信息钉在屏幕上参考；用完一秒收起，但内容仍可通过搜索重新找到。

**主要场景**

1. 从 PixPin、浏览器、微信、Word、Snipping Tool 等复制文字/图片，立即存入收集箱。
2. 保存某段代码、会议重点、工作截图，几天后用关键词或日期找回。
3. 把一张图或 Todo 贴在桌面上，边工作边对照；不用时双击隐藏。
4. 完成待办时获得短促、有点离谱的鼓励，不因此被频繁打扰。

**非目标**：完整笔记知识库、云端多人协作、默认持续监控全部剪贴板、复杂任务管理和积分养成体系。

## 02 · 产品结构

```text
系统托盘常驻
    │
    ├─ Ctrl + Alt + N ─► 快速面板（收集） ◄──► 历史（找回）
    │                       │                       │
    ├─ Ctrl + Alt + V ─► 快速收藏剪贴板             搜索/按日期过滤
    │                       │                       │
    │                       └──────────► 收集箱 ◄───┘
    │                                       │
    └──────────────────────────── 点击“钉住” ↓
                                    独立桌面浮贴
                                    ↳ 双击隐藏，不删除
```

- **收集箱**：所有保存过的信息的统一入口。默认隐藏，需要时一键呼出。
- **桌面浮贴**：只展示当前需要随时参照的信息。与收集箱中的内容引用同一条记录，而不是另建一份。
- **Todo**：卡片的一种内容类型，不是独立的重型项目管理模块。

## 03 · 核心交互契约

| 用户动作 | 行为 | 例外/边界 |
|---|---|---|
| `Ctrl + Alt + N` | 唤出或隐藏快速面板 | 可自定义；冲突时提示修改快捷键 |
| `Ctrl + Alt + V` | 将当前剪贴板可识别内容直接收藏；短暂提示“已保存” | 不打开主面板；无内容/不支持时明确提示 |
| `Ctrl + V`（面板内） | 粘贴当前剪贴板内容到当前卡片 | 文字、图片优先；不要求图片来自 PixPin |
| `Esc` | 关闭当前面板或退出弹层 | 编辑器内 `Esc` 不丢失已经自动保存的内容 |
| **鼠标左键双击主面板的非编辑区域** | **隐藏主面板** | 不拦截输入框选词、图片编辑操作、按钮或搜索结果双击打开 |
| **鼠标左键双击浮贴的可读区域** | **隐藏这一张浮贴** | 编辑状态下双击文字应选词；可从托盘或收集箱恢复 |
| 单击卡片 | 查看详情/进入编辑 | 不自动改变浮贴状态 |
| 点击卡片图钉 | 生成或恢复独立浮贴 | 再次点击取消浮贴，不删除内容 |
| 拖动浮贴 | 移动位置 | 吸附屏幕边缘为可选增强项 |
| 拖动浮贴边缘 | 改变尺寸 | 保持内容可读，图片按比例缩放 |
| 浮贴右键 | 精简菜单：置顶、透明度、编辑、从桌面收起、删除 | “收起”和“删除”视觉及文案明确区分 |

### 3.1 双击隐藏的防误触规则

- 主面板：标题栏、背景空白区域可双击隐藏；**输入、搜索、按钮、复选框、列表项等交互区域不执行隐藏**。
- 浮贴：**阅读模式**下，图片或卡片非编辑区域可双击隐藏；**编辑模式**中双击文字应遵循系统选词习惯。标题栏始终可双击隐藏。
- 双击只是改变窗口可见性，不删除、不取消收藏、不清空编辑内容。
- 窗口隐藏动画约 150–200 ms：纸张轻微缩小 + 淡出；可在“减少动画”中关闭。

### 3.2 收集流程

1. 呼出小面板（建议宽度约 420–480 px），自动聚焦编辑区。
2. 用户直接输入、`Ctrl+V` 粘贴，或切换 Todo 类型。
3. 内容更改后后台自动保存草稿；离开/隐藏面板时把本次记录完成归档。
4. 下次呼出默认进入新的空白快速记录；已保存内容从历史中继续编辑。
5. 可选“快速收藏”绕过面板，直接将当前剪贴板内容加入历史，并显示可撤销提示。

**关键原则**：不弹“另存为”、不要求命名、不要求选择分类。标题可自动从文字首行生成，图片默认用时间和缩略图呈现。

## 04 · 剪贴板兼容性

**来源无关，内容优先。** 用户复制自 PixPin、Windows 截图工具、浏览器、聊天软件、文档软件、图像软件等，只要 Windows 剪贴板提供可解读的图片或文字数据即可粘贴。

| 剪贴板数据 | v1 行为 |
|---|---|
| 纯文字/代码 | 创建文字卡片；保留换行；代码使用等宽排版 |
| 图片位图/PNG 等可解析图像格式 | 创建图片卡片；保留图像质量；支持附加文字说明 |
| 网址字符串 | 作为文字记录并识别为可点击链接 |
| 富文本/HTML | 优先提取安全、可读文字；不执行粘贴来的脚本 |
| 图文混合 | 同一卡片可分次粘贴多段文字与图片；一次粘贴若含多种格式，按明确优先级处理，避免重复创建 |
| 文件路径、文件对象、专有私有格式 | 不列为 v1 必须支持项；可提示不支持 |

- **默认不监听每次复制**，只有用户按快捷键或主动粘贴时才保存，减少复制密码、隐私信息时的意外收集。
- 面板的普通 `Ctrl+V` 不应被系统级“快速收藏”快捷键抢占。
- 对无法解码的剪贴板格式显示简洁提示，不 silently fail；已保存信息应保留图片原始内容，而非仅保留指向外部剪贴板的引用。
- 可追加文字说明；图片和备注作为同一条卡片搜索和归档。

## 05 · 找回与搜索

### 5.1 两种找法

- **关键字搜索**：匹配文字卡片、链接、Todo 任务文字、图片卡片的人工备注/标题。
- **按时间搜索**：快捷筛选“今天 / 最近 7 天 / 本月 / 自定义起止日期”；结果按日分组，展示时间。

两种搜索**可以组合**：例如在“最近 7 天”中搜索“FFT”。支持类型筛选：全部、图片、文字、待办。默认按创建时间倒序；支持切换为最后修改时间排序。

### 5.2 检索边界

- v1 **不承诺识别图片中的文字**；没有备注的截图仍可通过日期、缩略图浏览找回。
- 图中文字 OCR 搜索属于后续增强功能；不能把 OCR 当成首版依赖。
- 各记录在交互层面需有创建时间、修改时间；Todo 项可显示完成时间。如何持久化这些字段下一轮确定。
- 搜索结果单击预览、点图钉贴到桌面，不强制跳转到新页面。

## 06 · Todo：夸张但不过度的反馈

**基础体验**：勾选即完成，复选框轻弹、文字划掉、2–4 颗手绘小星星飘散；整张清单完成触发一次稍明显的纸屑/收纸动画。动画应短（约 300–700 ms），不遮挡其他窗口，无默认音效。

**文案语气**：夸张、嘴贫、自嘲、有趣。内容应偏善意，避免攻击用户、羞辱、年龄/性别等刻板印象，也避免长篇鸡汤。

**三档文案样例**

- **普通（建议权重 75%）**：
  - “任务已被你无情消灭，建议剩下的待办主动投降。”
  - “你的待办清单正在连夜申请工伤。”
  - “恭喜，今天的混乱被你撕开了一个口子。”
- **史诗（建议权重 23%）**：
  - “刚才 NASA 打来电话，问你这执行力能不能借他们用两天。”
  - “联合国紧急开会：要不要把今天定成你的纪念日？”
  - “这效率，生产队的驴看了都沉默。”
- **隐藏彩蛋（建议权重 2%）**：
  - “警告：你的生产力已突破本软件理论上限。开发者请求停火。”
  - “恭喜达成成就：待办收割机。请允许剩下的任务发表遗言。”
  - “生产力 +999，工资 +0。此处建议与老板友好协商。”

**触发控制**：默认勾选给出短反馈；快速连续勾选可合并提示，避免每项都弹窗。设置中可选“热情 / 克制 / 完全关闭文案”，另有“减少动画/关闭音效”。采用内置离线文案库，不需要 LLM API。

**可选彩蛋**：连续完成 5 项显示“待办收割机”；当天清空清单显示“今日 BOSS 已被击败”。只做短暂反馈，不引入积分货币、排名、连续签到惩罚。

## 07 · 视觉与布局规范

**关键词**：极简 / 轻手绘 / 温暖纸张 / 半透明 / Windows 桌面原生感。

- **色彩**：主色米白 `#F8F5ED`、墨蓝灰 `#283746`、淡雾蓝 `#DDE6EA`；点缀低饱和暖黄 `#F4E4B8`、柔绿 `#DDEBDD`。
- **手绘程度**：不追求凌乱的手写字体。保留系统正文无衬线字体，手绘感来自微微不规则的边框、小纸角、极少量星星/划线插画。
- **材质**：浮贴可调整不透明度（例如 60%–100%）；文字与图片本身要保持可辨识，透明主要用于卡片背景和玻璃容器。
- **工具按钮**：默认仅显示必要动作，鼠标悬停才显露置顶、透明度、编辑、关闭等。
- **布局**：默认只有宽约 420–480 px 的快速面板；切换找回模式时展开成宽约 580–700 px 的纵向时间列表。不设置永久侧边栏。
- **动画**：轻且短；遵循 Windows 减少动画系统设置，低性能设备可以关闭模糊效果。
- **可读性**：字号、对比度、键盘焦点可辨识；不得为了磨砂效果牺牲文字清晰度。

### 三个主要界面

1. **快速捕捉**：小标题栏 + 一块空白编辑区 + 简单的文字/图片/Todo 切换 + “自动保存”提示。
2. **时间找回**：顶部搜索框 + 日期/类型筛选 + 按日分组的紧凑记录列表（图片小缩略图）。
3. **桌面浮贴**：干净的单张纸；默认没有可见标题栏工具条，鼠标悬停出现控制按钮。

## 08 · 主要用户路径

### 路径 A — 从任意软件收藏图片

`复制图片 → Ctrl+Alt+V → “已保存”短提示 → 继续原工作 → Ctrl+Alt+N → 搜索/按日期找到图片 → 📌 钉住`。

### 路径 B — 记一段临时文字

`Ctrl+Alt+N → 直接输入/粘贴 → 自动保存 → 双击面板空白区域隐藏 → 下次从历史找到并修改`。

### 路径 C — 手绘风 Todo

`Ctrl+Alt+N → 新建 Todo → 输入任务 → 钉到桌面 → 勾选一项 → 小星星 + 嘴贫文案 → 双击浮贴隐藏`。

### 路径 D — 找回上周的截图

`Ctrl+Alt+N → 找回 → 最近 7 天 → 筛选图片 → 浏览缩略图 / 输入备注关键词 → 打开/钉住`。

## 09 · v1 功能边界及验收点

| 模块 | v1 必须有的验收结果 |
|---|---|
| 启动/托盘 | 程序可从托盘呼出，不需要一直展示主窗口 |
| 快捷键 | `Ctrl+Alt+N` 可切换面板显隐；`Ctrl+Alt+V` 可主动收藏；处理热键占用 |
| 剪贴板 | 至少覆盖常见 Windows 文字格式和截图图片格式；来源不限 |
| 快速记录 | 文字/图片/Todo 可创建和编辑，改动不因关闭面板丢失 |
| 搜索 | 关键词 + 日期范围组合筛选；按日分组；按类型筛选 |
| 浮贴 | 独立拖动、缩放、置顶、调透明度；阅读模式双击隐藏；可再次恢复 |
| Todo | 勾选状态变化、短动画、随机幽默文案、可关闭效果 |
| 容错 | 双击不会删内容；不支持的粘贴格式有提示；删除有明确确认或撤销 |
| 体验 | 无强制登录、无默认剪贴板自动监控、无云端 API 依赖 |

### 首版暂不做

OCR 图片文字检索、在线同步、跨设备共享、多人协作、AI 自动分类、复杂富文本编辑、多媒体/附件、积分商城、复杂标签树。

## 10 · 下一轮讨论：用户数据怎么存（暂不做决定）

本版只确认以下**使用层面的数据约束**，暂不选择 SQLite/JSON/目录格式等落地方案：

1. 图片必须真正保存在用户设备上，不能依赖当前剪贴板、PixPin 进程或临时缓存。
2. 用户无需手工起文件名，但必须能备份、迁移、导出自己的内容。
3. 必须能记录文字、图片、Todo、备注、创建/修改/完成时间、浮贴位置/尺寸/置顶/透明度。
4. 应考虑异常退出、磁盘空间、误删恢复，以及“清空所有数据”时的可预期行为。
5. 默认本地优先，未来是否支持加密、备份、同步由下一轮决定。
6. 需要评估剪贴板敏感内容的隐私边界（特别是将来若提供可选自动监听时）。

**下一轮讨论建议按顺序**：文件落盘与元数据组织 → 搜索索引 → 数据迁移/备份 → 敏感数据与加密 → 数据大小与性能上限。

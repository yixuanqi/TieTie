# v0.4.5 — 原生圆角与暗色主题外观修复

## 现象

用户在 v0.4.4 暗色模式观察到主窗口直角、部分区域“尖出来”。v0.4.4 使用 `transparent:false` 并把 `.main-body` 填满窗口矩形，导致 CSS 的 `border-radius` 不能影响真正的 HWND 四角。

## 方案

* `tauri.conf.json`：主窗口继续 `transparent:false`，保留原生可缩放窗口；关闭可能形成额外白边的系统 shadow。
* Win32：使用 `CreateRoundRectRgn` / `SetWindowRgn` 裁剪主面板、设置窗口的 HWND；随 resize 事件同步更新，重复物理尺寸时跳过。
* `styles.css`：两个窗口内层面板恢复 21px 圆角，亮/暗色仍用纯色背景。浮贴保持旧实现。
* 安全：原生区域成功交给 `SetWindowRgn` 后不再手动释放；失败时回收句柄并允许后续重试；非 Windows 代码被 `cfg(windows)` 守卫。
* 缩放：21 CSS 像素半径由 WebView DPI 映射成 Win32 物理像素椭圆直径。
* 数据：没有修改持久化、现有记录或偏好结构。

## 回归与风险

* `node --check`、模拟 UI / 设置 / 性能测试、圆角配置契约测试通过。
* Win32 API 尚未在 Windows/MSVC 实机编译和视觉验收，圆角锯齿及拖动时是否存在短暂闪烁需要在目标电脑上检查。
* 附 `tests/check_windows_rounding.ps1`，可验证 GetWindowRgn，不代表实际 UI 像素测试。

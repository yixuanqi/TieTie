# 贴贴 v0.4 · 开发变更记录

## 从可交互网页原型变为 Windows 桌面程序

- 运行容器从浏览器改为 Tauri 2 + Windows WebView2；托盘与窗口管理由 Rust/Tauri 完成。
- 由 Rust 注册全局 `Ctrl+Alt+N` / `Ctrl+Alt+V`，快捷键不是浏览器页内监听。
- 由原生剪贴板库读取可解码的 Unicode 文本与位图，PNG 由 Rust 写入应用数据目录。
- 主面板维持「随手记 / 找回来」两层，视觉保留米白、雾蓝和纸张感。
- 浮贴由独立的 OS 窗口实现，非网页中绝对定位的 `div`；支持置顶、缩放及透明度。
- 采用只在用户按快捷键/主动粘贴时收集，不监控每次复制。
- 首版使用 JSON + PNG 暂存，保留迁移和替换存储策略的边界。

## 验证情况

- Node.js 对 `web/app.js`、`web/float.js` 语法检查通过。
- Chromium + 模拟 Tauri 桥接的冒烟测试：文字自动保存、关键词搜索、浮贴钉住、Todo 创建和勾选成功；无 JS 异常。
- **没有实际运行 Rust 编译或 Windows 原生接口测试**：环境无 Rust/MSVC，npm 镜像当前解析不可用；请通过 Windows `npm install && npm run dev` 或仓库 Windows CI 检验。
